# 첫직관

> 슬기로운 직관생활 — 처음 가는 야구장, 예매부터 응원까지

야구장에 처음 가는 사람을 위한 직관 가이드 앱입니다. 내 팀을 고르면 예매 오픈 시점, 좌석 고르는 법, 꼭 알아야 할 룰, 응원 방법을 한곳에서 볼 수 있고, 다녀온 경기는 티켓처럼 모아 기록합니다.

- 시안 보기: `index.html`을 브라우저에서 열면 됩니다 (빌드 과정 없음)
- 현재 단계: 홈 화면 시안 (정적 HTML, 예시 데이터)

---

## 기획

### 왜 만드나
경기 일정과 결과는 포털 스포츠 서비스에서 이미 잘 보여 줍니다. 하지만 **처음 가는 사람**에게 필요한 정보는 흩어져 있습니다.

- 예매처와 오픈 시각이 구단마다 다르다 (구단 앱, 예매 사이트 등)
- 어느 좌석이 응원석인지, 처음이면 어디가 좋은지 알기 어렵다
- 낫아웃, 인필드 플라이처럼 경기를 보다가 헷갈리는 룰을 바로 찾기 어렵다
- 다녀온 경기를 남겨 둘 곳이 마땅치 않다

첫직관은 **결과를 보여 주는 앱이 아니라, 경기장에 가는 과정을 도와주는 앱**입니다.

### 누구를 위한가
- 친구나 연인을 따라 처음 야구장에 가는 사람
- 팀은 정했지만 룰과 응원 문화가 아직 낯선 신규 팬
- 직관 기록을 모으고 싶은 라이트 팬

### 핵심 기능

| 기능 | 내용 |
|---|---|
| 홈 | 내 팀의 다음 경기를 티켓 한 장으로 보여 줌. D-day 도장, 예매 오픈 알림 |
| 예매 안내 | 구단별 예매처, 오픈 시점, 예매 순서 |
| 룰 카드 | 종목마다 "점수 / 아웃·출루 / 헷갈리는 룰" 형식으로 통일한 카드 |
| 직관 준비 | 구장 가는 법, 좌석 고르기, 준비물, 응원 방법 (응원가는 외부 링크) |
| 직관 기록 | 다녀온 경기를 티켓으로 붙이고 짧은 메모를 남김 |
| 퀴즈 | 룰 카드에서 배운 내용을 한 문제씩 확인 |

### MVP 범위
1. KBO 10개 구단 선택과 팀 컬러 적용
2. 구단별 예매 안내 10개
3. 야구 룰 카드 10장
4. 직관 기록 (브라우저 저장)

### 화면 구성
하단 메뉴: **홈 · 예매 · 룰 · 준비 · 기록**

```
홈
├─ 다음 직관 (티켓 + D-day 도장)
├─ 예매 오픈 알림
├─ 내 직관 기록 (최근 2장)
├─ 룰 카드 (오늘의 3장)
└─ 오늘의 퀴즈
```

### 데이터
- 리그 공식 API가 없어서 초기에는 **수동으로 입력하고 검수**합니다.
- 예매 정책, 구장 정보처럼 자주 바뀌지 않는 정보부터 다룹니다.
- 경기 일정처럼 바뀌는 정보는 출처와 기준일을 함께 표시합니다.

### 확장 계획
야구 다음에는 같은 구조(연고지, 예매, 룰 카드, 직관 준비)로 다른 구기 종목을 붙입니다.

| 종목 | 리그 | 시즌 |
|---|---|---|
| 야구 | KBO (10팀) | 3월 ~ 10월 |
| 남자농구 | KBL (10팀) | 10월 ~ 이듬해 4월 |
| 여자농구 | WKBL (6팀) | 겨울 시즌 |
| 배구 | V-리그 (남녀 각 7팀) | 10월 말 ~ 이듬해 4월 |
| 핸드볼 | H리그 | 11월 ~ 이듬해 5월 무렵 |

야구가 끝나는 가을에 농구와 배구가 시작해서, 1년 내내 "다음 직관"을 이어 갈 수 있습니다.

## 디자인

**콘셉트: 직관 일기장.** 야구장 종이 티켓을 모으는 스크랩북입니다. 화면의 주인공은 티켓입니다.

- 모눈 노트 바탕, 감열지 티켓(팀 컬러 띠, 절취선, 바코드), 팀 컬러 도장
- 내 팀을 고르면 강조색 전체가 그 팀 컬러로 바뀜
- 문구는 짧고 담백하게
- 글꼴: KBO 다이아고딕(본문, 티켓) + 개구(손글씨 메모)

자세한 기준은 [DESIGN.md](DESIGN.md)에 있습니다.
