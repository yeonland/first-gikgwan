# 첫직관

> 슬기로운 직관생활 — 처음 가는 경기장, 예매부터 응원까지

야구, 축구, 농구, 배구, 핸드볼, 아이스하키 경기장에 처음 가는 사람을 위한 직관 가이드 앱입니다. 내 팀을 고르면 예매 오픈 시점, 좌석 고르는 법, 꼭 알아야 할 룰, 응원 방법을 한곳에서 볼 수 있고, 다녀온 경기는 티켓처럼 모아 기록합니다.

- **사이트: https://yeonland.github.io/first-gikgwan/**
- 로고 시안: https://yeonland.github.io/first-gikgwan/drafts/logo.html
- 로컬에서 보기: `index.html`을 브라우저에서 열면 됩니다 (빌드 과정 없음)
- 현재 단계: 야구·배구 (홈·예매·룰 카드·직관 준비·직관 기록. 정적 HTML)

---

## 기획

### 왜 만드나
경기 일정과 결과는 포털 스포츠 서비스에서 이미 잘 보여 줍니다. 하지만 **처음 가는 사람**에게 필요한 정보는 흩어져 있습니다.

- 예매처와 오픈 시각이 구단마다 다르다 (구단 앱, 예매 사이트 등)
- 어느 좌석이 응원석인지, 처음이면 어디가 좋은지 알기 어렵다
- 낫아웃, 인필드 플라이처럼 경기를 보다가 헷갈리는 룰을 바로 찾기 어렵다
- 다녀온 경기를 남겨 둘 곳이 마땅치 않다

첫직관은 **결과를 보여 주는 앱이 아니라, 경기장에 가는 과정을 도와주는 앱**입니다.

### 누구를 위한가
- 친구나 연인을 따라 처음 야구장에 가는 사람
- 팀은 정했지만 룰과 응원 문화가 아직 낯선 신규 팬
- 직관 기록을 모으고 싶은 라이트 팬

### 핵심 기능

| 기능 | 내용 |
|---|---|
| 홈 | 내 팀의 다음 경기를 티켓 한 장으로 보여 줌. D-day 도장, 예매 오픈 알림 |
| 예매 안내 | 구단별 예매처, 오픈 시점, 예매 순서 |
| 룰 카드 | 종목마다 "점수 / 아웃·출루 / 헷갈리는 룰" 형식으로 통일한 카드 |
| 직관 준비 | 구장 가는 법, 좌석 고르기, 준비물, 응원 방법 (응원가는 외부 링크) |
| 직관 기록 | 다녀온 경기를 티켓으로 붙이고 짧은 메모를 남김 |
| 퀴즈 | 룰 카드에서 배운 내용을 한 문제씩 확인 |

### MVP 범위
1. KBO 10개 구단 선택과 팀 컬러 적용
2. 구단별 예매 안내 10개
3. 야구 룰 카드 10장
4. 직관 기록 (브라우저 저장)

### 화면 구성
하단 메뉴: **홈 · 예매 · 룰 · 준비 · 기록**

```
홈
├─ 다음 직관 (티켓 + D-day 도장)
├─ 예매 오픈 알림
├─ 내 직관 기록 (최근 2장)
├─ 룰 카드 (오늘의 3장)
└─ 오늘의 퀴즈
```

### 데이터
- 리그 공식 API가 없어서 초기에는 **수동으로 입력하고 검수**합니다.
- 예매 정책, 구장 정보처럼 자주 바뀌지 않는 정보부터 다룹니다.
- 경기 일정처럼 바뀌는 정보는 출처와 기준일을 함께 표시합니다.

### 다루는 종목 (7개)
홈팀, 경기장, 시즌이 있는 국내 리그만 다룹니다. 모든 종목을 같은 구조(연고지, 예매, 룰 카드, 직관 준비)로 만듭니다.

| 종목 | 리그 | 시즌 |
|---|---|---|
| 야구 | KBO (10팀) | 3월 ~ 10월, 포스트시즌 11월 초 |
| 축구 | K리그1 (12팀) | 2월 말 ~ 11월 |
| 남자농구 | KBL (10팀) | 10월 ~ 이듬해 4월 |
| 여자농구 | WKBL (6팀) | 11월 ~ 이듬해 3월 |
| 배구 | V-리그 (남녀 각 7팀) | 10월 말 ~ 이듬해 4월 |
| 핸드볼 | H리그 (남 6팀, 여 8팀) | 11월 ~ 이듬해 5월 초 |
| 아이스하키 | 아시아리그 (국내 HL 안양) | 가을 ~ 이듬해 봄 (확인 필요) |

어느 달이든 최소 두 리그가 열립니다. 여름에는 야구와 축구, 겨울에는 실내 종목이 이어져 1년 내내 "다음 직관"이 있습니다.

**만드는 순서**: 야구 → 겨울 종목 묶음(농구, 배구, 핸드볼, 아이스하키) → 축구

**검토 후 제외**: 골프(갤러리 문화는 있지만 홈팀·고정 경기장이 없음), 당구(대부분 중계로 관람), e스포츠(운동 경기가 아님)

## 디자인

**콘셉트: 직관 일기장.** 야구장 종이 티켓을 모으는 스크랩북입니다. 화면의 주인공은 티켓입니다.

- 민무늬 종이 바탕, 감열지 티켓(팀 컬러 띠, 절취선, 바코드), 팀 컬러 날짜 소인
- 날짜·시간·D-day·스코어는 야구장 전광판처럼 도트 숫자로 표시
- 내 팀을 고르면 강조색 전체가 그 팀 컬러로 바뀜
- 문구는 짧고 담백하게
- 글꼴 3종: 강원교육새음(로고, 손글씨 메모) + KBO 다이아고딕(본문, 티켓) + DotGothic16(전광판 숫자)

**로고: 도장 두 개**
- **꽃 도장**: 앱 로고와 아이콘. 가운데 야구공을 농구·축구·배구·핸드볼공과 아이스하키 퍽이 둘러쌉니다 (공 다섯 개 + 퍽 = 7종목)
- **날짜 소인**: 하루 첫 실행 때 오늘 날짜로 찍히는 첫 화면이자, 직관 기록에 그 경기 날짜로 찍히는 도장
- 시안: [drafts/logo.html](drafts/logo.html)

자세한 기준은 [DESIGN.md](DESIGN.md)에 있습니다.

## 파일 구성

```
first-gikgwan/
├─ index.html   앱 화면 (모든 종목이 같이 쓰는 화면 코드)
├─ data/        종목별 데이터. 고른 종목 파일만 불러옴 (baseball.js, volleyball.js)
├─ DESIGN.md    디자인 기준
├─ drafts/      로고 시안, 첫 홈 화면 시안(first-jikgwan.html)
└─ fonts/       KBO 다이아고딕 (woff)
```

강원교육새음 글꼴 파일은 재배포 금지라 저장소에 넣지 않았습니다. 파일이 없으면 눈누 CDN에서 불러옵니다.

## 참고
- 화면의 경기, 좌석 정보와 기록이 없을 때 홈에 보이는 티켓 2장은 예시 데이터입니다. 직관 기록은 사용자의 브라우저(localStorage)에만 저장됩니다.
- 구단 컬러는 Figma에 정리한 색 스타일(구단별 메인·서브)을 따릅니다.
- 룰 카드의 조항 번호는 [KBO 2026 공식야구규칙](https://6ptotvmi5753.edge.naverncp.com/KBO_FILE/ebook/pdf/2026_%EC%95%BC%EA%B5%AC%EA%B7%9C%EC%B9%99.pdf)(KBO 발행)과 대조했습니다. 규칙서는 [한국야구소프트볼심판아카데미 야구규칙서 게시판](http://www.umpire.or.kr/?act=board&bbs_code=sub5_5)에서 찾았고, 저작권 때문에 PDF는 저장소에 넣지 않습니다. 카드 문장은 규칙서를 옮기지 않고 풀어 썼습니다.
- 배구 룰 카드의 조항 번호는 [대한배구협회](https://www.kva.or.kr/user/template.do?fileNm=vlb2_1) 배구경기규칙서(2025~2028)와 대조했습니다. 규칙서 PDF는 저장소에 넣지 않습니다. V-리그 일정·예매처는 [KOVO](https://kovo.co.kr) 기준(2026.10.13 확인)입니다.
- 구장 지도의 윤곽은 [Natural Earth](https://www.naturalearthdata.com/)(퍼블릭 도메인), 구장 좌표는 © [OpenStreetMap](https://www.openstreetmap.org/copyright) 기여자 기준입니다.
