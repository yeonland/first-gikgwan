# 구단 공식 페이지 모음

공식 팀 색, 마스코트, 응원가를 확인할 때 쓰는 주소 모음입니다. 홈페이지는 앱 데이터(data/*.js의 clubUrl)에 들어 있는 주소입니다.
빈 칸은 아직 찾지 않은 곳입니다. 찾으면 칸을 채우고, 앱에 넣을 것(응원가 페이지 → cheerUrl, 확정 색 → teams)은 데이터 파일에도 넣습니다.

- 팀 색 검색어: `[구단 이름] BI`, `[구단 이름] CI 컬러`
- 마스코트 검색어: `[구단 이름] 마스코트`
- 응원가 검색어: `[구단 이름] 응원가`
