# 응원 도구 정리 (2026-10-17 시작)

응원 도구: 응원봉, 막대풍선, 응원 타월, 짝짝이(클래퍼), 머리띠처럼 경기장에서 응원할 때 쓰는 물건.
**앱에 넣은 것**은 출처가 확인된 것만입니다. 직접 산 것, 구단 공식 몰에서 본 것을 아래 칸에 붙여 넣으면 앱에 옮깁니다.
중고 거래 사이트 글은 공식 상품인지 알 수 없어서 넣지 않습니다.

## 이미 앱에 넣은 것 (준비 탭 응원 방법 > 응원 도구)
출처: [위키백과 '대한민국의 야구 응원 문화'](https://ko.wikipedia.org/wiki/%EB%8C%80%ED%95%9C%EB%AF%BC%EA%B5%AD%EC%9D%98_%EC%95%BC%EA%B5%AC_%EC%9D%91%EC%9B%90_%EB%AC%B8%ED%99%94), [스포츠경향 2009.10 기사](https://sports.khan.co.kr/article/200910132042313)

- 공통: 막대풍선 두 개를 맞부딪혀 박자 맞추기, 응원 타월 머리 위로 흔들기
- 롯데: 신문지 응원, 짝짝이(클래퍼)
- KIA: 노란 막대풍선 ("단무지")

## 공식 굿즈샵 (2026-10-17 확인)
확인 방법: 구단 공식 홈페이지에 그 쇼핑몰 연결이 있는지, 쇼핑몰 맨 아래 운영 회사가 누구인지 직접 봄.
**앱에 넣음**은 팀을 고르면 응원 도구 줄에 "○○ 공식 굿즈샵" 링크로 나옵니다. 앱에 안 넣은 구단은 KBO 마켓으로 연결합니다.
상품 사진과 설명 글은 저작권 때문에 가져오지 않고, 주소만 연결합니다.
